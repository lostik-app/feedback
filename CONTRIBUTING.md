# Как отправить обращение

Выберите форму ошибки, предложения или проблемы с интерфейсом. Сначала проверьте существующие обращения. Для каждой проблемы создавайте отдельное.

Для ошибки опишите шаги, ожидаемый и фактический результат, браузер и устройство. Для проблемы с интерфейсом укажите экран и приложите скриншот без лишнего содержимого.

Обращения видны всем. Не прикладывайте личные переписки, пароли, токены, файлы сессий и выгрузки данных. Об уязвимостях сообщайте через закрытую форму в разделе Security.

Метка «в планах» не обещает срок выпуска. Если похожее обращение уже есть, дополните его вместо создания копии.
